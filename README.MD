# Personal Research Portfolio Website

A responsive, single-page personal website starter for an academic/research profile.

## Preview locally
1. Extract the ZIP file.
2. Open the `personal_website` folder.
3. Double-click `index.html` to open it in your browser.

## Personalize before publishing
Open `index.html` in VS Code and replace:
- `Your Name` with your preferred public name.
- `YS` in the navigation logo with your initials.
- `your.email@example.com` with your public contact email.
- GitHub and LinkedIn placeholder URLs with your real profile URLs.
- The About, research, project, and academic-profile text with your final details.

Add a CV PDF in this folder and add a link to it if you want a downloadable CV.

## Publish free with GitHub Pages
1. Create a public GitHub repository, for example `your-username.github.io`.
2. Upload `index.html`, `style.css`, `script.js`, and this README to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Wait for GitHub Pages to publish. Your site will be available at `https://your-username.github.io`.

You can also use a repository with another name; its website URL will include that repository name.

## Notes
- This starter uses Google Fonts, so the font styling requires an internet connection.
- The project descriptions are starter copy based on the research and technical areas discussed; edit them to accurately represent completed work versus work in progress.
